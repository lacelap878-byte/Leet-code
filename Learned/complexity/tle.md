# Time Limit Exceeded

**In one line:** TLE means the code was too slow for a test, not that the answer was wrong.

- LeetCode gives each test about a second. If my code is still running, it is stopped and I get TLE. The tests before it passed.
- I count TLE as wrong. A solution has to be correct **and** fast.
- A "Follow up" on LeetCode is an extra challenge, not a requirement. 347's follow-up asks for better than $O(n \log n)$.
