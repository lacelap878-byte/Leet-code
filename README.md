# LeetCode practice

My own solutions in C++, each one written from a blank page. Practice for coding and problem-solving.

## How I work

1. Try the problem alone for about 30 minutes.
2. If I'm stuck: read a hint, then the solution.
3. Close everything and re-solve it from a blank page.
4. Redo it a few days later.

No AI-written solutions. AI only explains, after an honest attempt.

## Layout

```
solutions/<pattern>/<number>-<name>.cpp
```

Example: `solutions/arrays-hashing/0001-two-sum.cpp`

`LOG.md` has one line per practice session.

## Order of patterns

Easy problems first, one pattern at a time:

1. arrays-hashing
2. two-pointers
3. sliding-window
4. stack
5. binary-search
6. linked-list
7. trees
8. the rest, once these feel familiar
