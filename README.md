# LeetCode practice

My own solutions in C++, each one written from a blank page. Practice for coding and problem-solving.

## How I work

1. Try the problem alone for about 30 minutes.
2. If I'm stuck: read a hint, then the solution.
3. Close everything and re-solve it from a blank page.
4. Redo it a few days later.

No AI-written solutions. AI only explains, after an honest attempt.

## Layout

```
submissions/<pattern>/<number>-<Name>.cpp
Learned/
LOG.md
```

- `submissions/`: my solutions. Example: `submissions/array-hashing/0001-Two_Sum.cpp`. Numbers have four digits so the files stay in order.
- `Learned/`: everything I learn for the first time, filed by idea. Start at `Learned/README.md`.
- `LOG.md`: one line per practice session.
